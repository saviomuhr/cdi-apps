# CDI Apps

Apps publicados pelo GitHub Pages para instalar no tablet pelo Chrome.

- `ancoragem/ilhabela/`: Plano de Ancoragem para Andaime (FPSO Cidade de Ilhabela), gerado por `build_ancoragem.py` (pasta `build/web/Ilhabela/`).
- `rdc/ilhabela/`: RDC Daily Report de Fabric Maintenance, gerado por `build.py` (pasta `build/web/RDC_Ilhabela/`).
- `rdc-pintura/ilhabela/`: RDC Pintura, gerado por `build.py` (pasta `build/web/RDC_Pintura_Ilhabela/`).

Para atualizar, copie a pasta gerada pelo build para cá e publique. O app instalado baixa a versão nova na próxima abertura com internet.
